# Stellar Cellar

Home Assistant add-on repository. Wine cellar tracker with QR labels, drinking windows,
price tiers, label-photo reading and Claude picks from the bottles you own.

Add this repository URL in **Settings → Add-ons → Add-on Store → ⋮ → Repositories**,
then install **Stellar Cellar**. Details in [cellar/README.md](cellar/README.md).
